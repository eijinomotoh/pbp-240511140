# Refleksi

## 1. Platform yang paling menarik untuk dipelajari

Dari ketiga platform, saya paling tertarik mempelajari platform web. Web bisa diakses dari perangkat apa pun hanya lewat browser tanpa instalasi, sehingga jangkauan penggunanya luas dan pembaruan aplikasi bisa dilakukan seketika. Saya juga merasa web lebih mudah dipelajari secara bertahap, mulai dari HTML, CSS, dan JavaScript, lalu berlanjut ke framework dan sisi server dengan Node.js. Hasil kerja pun bisa langsung terlihat di browser, sehingga proses belajarnya terasa menyenangkan.

## 2. Tantangan terbesar saat setup environment

Tantangan terbesar yang saya hadapi saat setup environment adalah memastikan seluruh tools terpasang dengan benar, terutama Node.js dan NPM, agar perintah di terminal dapat dikenali. Selain itu, salah satu kendala khas pada platform web adalah tampilan yang bisa berbeda di berbagai ukuran layar dan browser, sehingga halaman yang rapi di laptop bisa berantakan di ponsel.

## 3. Rencana mengatasi tantangan

Untuk mengatasinya, saya berencana menambahkan fitur yang responsif dan informatif pada proyek web saya. Dengan desain responsif, menggunakan media query, flexbox, dan grid, tampilan akan menyesuaikan berbagai perangkat. Dengan konten yang informatif, yaitu informasi yang jelas, terstruktur, dan mudah dibaca, pengguna dapat memahami isi halaman tanpa kebingungan. Saya juga akan menguji tampilan di beberapa browser dan membaca dokumentasi resmi seperti MDN Web Docs.
